# 饮酒监控器

一个轻量、无外部运行依赖的饮酒记录工具，支持手机和电脑。

在线使用：[饮酒监控器](https://robgun.github.io/alcohol-monitor/)

## 记录饮酒

- 选择啤酒、葡萄酒或烈酒，或点选最近喝过的酒款，快速填写表单。
- 修改实际饮酒量和瓶身酒精度，品牌选填。预设数值不代表所有酒款的实际酒精度。
- 容量支持毫升和美制液体盎司；点击容量按钮可快速填写，数字框支持小数。
- 日期默认今天，可一键选昨天，也可通过日期框补记。不能录入未来日期。
- 保存前显示本次英国酒精单位。保存成功后保留酒款与容量，方便下一次记录。
- 历史记录按饮酒日期分组；“再记一杯”填入同样酒款并把日期设为今天，确认保存后才会新增。
- 保存和删除后支持撤销最近一次操作，撤销提示保留到关闭或下一次操作。

## 统计口径

- **最近七天**：今天及之前六个当地自然日，不是周一到周日，也不是精确的过去 168 小时。
- **今日**：当前当地日期。
- **近三日**：今天及之前两个当地自然日。
- 英国酒精单位 = 饮酒量（ml）× 酒精度（%）÷ 1000；1 美制液体盎司 = 29.5735 ml。
- NHS 建议不要经常每周超过 14 单位，如果喝到这个量，应分散在至少三天。工具用最近七天累计值对照每周参考上限。
- 今日 4.5 单位、三日 13.5 单位沿用原工具的提醒值，不是 NHS 的每日或三日标准。低于提醒值不代表没有健康风险。

参考：[NHS 酒精单位说明](https://www.nhs.uk/live-well/alcohol-advice/calculating-alcohol-units/)

## 数据兼容与保存

- 继续使用原有 `alcohol_monitor_drinks_v2` 与 `alcohol_monitor_brands_v2` 本地存储键；同一网址、同一浏览器下，已有有效记录可直接读取，无需迁移。
- 保留旧的中文页面路径及根目录跳转，原书签继续有效。
- 记录只在当前浏览器本地保存，不上传 GitHub，不会自动跨设备同步。清除网站数据会删除记录。
- 数据损坏时显示错误，保留原始内容并停止新增，避免以空数据覆盖旧记录。
- 保存失败时保留表单输入并明确提示，不显示虚假的保存成功。
- 同源其他标签页的更新会刷新统计；每次修改前重新读取存储，减少旧页面覆盖新数据的问题。本地存储不是多设备或多用户数据库。

## 项目结构

- `index.html`：保留的默认入口。
- `饮酒监控器.html`：页面结构。
- `styles.css`：响应式界面、触摸操作与键盘焦点样式。
- `core.js`：日期、计算、数据验证与兼容读取，可独立测试。
- `app.js`：录入、统计、历史、撤销与本地存储交互。
- `tests/core.test.cjs`：关键逻辑回归测试，无额外依赖。

## 开发与部署

使用任意静态 HTTP 服务预览，无需安装依赖或构建。GitHub Pages 沿用 `main` 分支根目录部署。

Node.js 18+ 可运行核心测试：

```sh
node --test tests/core.test.cjs
```

日期逻辑可在不同时区下检查：

```sh
TZ=Asia/Shanghai node --test tests/core.test.cjs
TZ=America/New_York node --test tests/core.test.cjs
```

# 饮酒监控器

一个轻量的单文件饮酒记录工具，用来快速记录每天喝了什么、喝了多少，并查看当日与本周的饮酒统计。

在线使用：

- GitHub Pages 部署后可直接通过浏览器访问
- 支持手机和电脑浏览器
- 可添加到手机主屏幕，作为快捷入口使用

## 功能

- 记录品牌、酒精度、饮酒量和日期
- 自动统计今日纯酒精摄入量和酒精单位
- 自动统计本周累计饮酒情况
- 显示历史记录，并支持删除或重复添加
- 支持常见品牌快速输入

## 使用方式

1. 打开页面
2. 输入品牌、酒精度、饮酒量和日期
3. 点击“保存本条记录”
4. 在页面上方查看今日和本周统计
5. 在历史记录区回看、删除或重复添加记录

## 手机使用

- 直接在手机浏览器中打开页面
- 可通过浏览器的“添加到主屏幕”功能保存到桌面
- 页面已适配移动端布局

## 数据说明

- 所有记录都保存在当前浏览器的本地存储 `localStorage` 中
- 默认不会上传到服务器
- 不同设备之间不会自动同步数据
- 同一设备上的不同浏览器通常也不会共享数据

## 适合场景

- 个人日常饮酒记录
- 控制短期饮酒频率和摄入量
- 通过简单页面快速完成录入，不依赖复杂 App

## 项目结构

- `index.html`：默认入口页
- `饮酒监控器.html`：主页面与全部功能实现
